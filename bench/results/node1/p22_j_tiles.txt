# GPU4PySCF investigation part 22 (NOTES.md): the J engine's launch tiles sized to fill the SMs.
# GTX 1650 Super at 1530 MHz (20 SMs); caffeine; J at the converged B3LYP densities (scratch/dm_caf_b3lyp.npy,
# scratch/dm_caf_tzvp_b3lyp.npy). "N dm" builds N densities at once: the density and N-1 symmetric variations with its
# sparsity (jk_at_dm.py --ndm N), which run the multi-density kernels (unrolled_md_j_4dm.cu, md_j_4dm_kernel).
# Trees:
#   part 21    scratch/tree_p21: exp/prim-screen c6c7ce0, fixed tiles
#   unrolled   the main tree with exp/prim-screen ef2327e's unrolled kernels: run-time bra tiles, at least
#              MD_J_BLOCKS_PER_SM blocks per SM (64 unless swept)
#   + generic  scratch/tree_p22b: also perf 452c283's j_engine.py, the generic kernel's bra tile cut the same way
#   final      exp/prim-screen fb338f2: both, and no empty bra tiles (md_j_grid_x, section 5)
#
# Commands (node1; the scripts are in scratch/):
#   p22_run.sh                  jk_at_dm.py --part j, scf_parts.py and unit tests on the first build (4 blocks per SM)
#   p22_sweep.sh, p22_sweep2.sh rebuild at MD_J_BLOCKS_PER_SM 1, 2, 8, 16, 4, then 32, 64, 128, 256, 4; J  (section 2)
#   p22_final.sh                J and scf_parts.py --verbose 6 at 64 blocks per SM against part 21; unit tests
#                                                                                              (sections 1, 4, 7)
#   p22b.sh                     the generic kernel's cut                                       (sections 3, 4)
#   p22_memcheck.sh, p22_fix.sh compute-sanitizer --tool memcheck on j_memcheck.py (CuPy's memory pool off),
#                               before and after the fix; J and unit tests on the final tree   (sections 5, 6, 7)
